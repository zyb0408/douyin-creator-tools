# 抖音创作者自动回复 — 油猴脚本

在抖音**创作者中心评论管理页**自动回复评论，支持 LLM 根据评论内容生成个性化回复、自定义模板、混合模式与定时扫描。

> 这是 [`douyin-creator-tools`](../) 的浏览器轻量版。和 Node.js 工具回复风格一致（system prompt、过滤规则原样移植），但**数据完全独立**：不访问 SQLite，去重仅靠页面"未回复"筛选 tab，适合每天数十到数百条的轻量场景。

---

## 安装

### 1. 安装 Tampermonkey

| 浏览器 | 来源 |
|--------|------|
| Chrome / Edge | Chrome 应用商店搜索「Tampermonkey」 |
| Firefox | Firefox 附加组件页面搜「Tampermonkey」 |

### 2. 添加脚本

1. 点浏览器右上角 🧩 → 「添加新脚本」
2. **全选删掉编辑器里的默认内容**
3. 把 `userscripts/douyin-auto-reply-userscript.js` 全部内容复制粘贴进去
4. `Ctrl + S` 保存

### 3. 验证安装

1. 打开 `https://creator.douyin.com/creator-micro/comment-manage`
2. 登录后查看页面右下角，应看到一个蓝色 🤖 圆形悬浮按钮
3. 点击 🤖 → 配置面板弹出 → 安装成功

如果看不到按钮，按 `F12` → Console，搜索 `[抖音自动回复]`：能看到 `loaded v0.1.0` 说明脚本已加载，可能是 CSS 冲突；找不到说明 Tampermonkey 没匹配上，检查 `@match` 是否被改过。

## 使用

### 配置面板

| 区域 | 说明 |
|------|------|
| **基础设置** | 启用开关、回复模式、要遍历的作品数 N |
| **定时扫描** | 开关、间隔（最低 5 分钟）、可选"立即先跑一次" |
| **自定义模板** | 每行一条，模板模式与混合模式回退用 |
| **LLM 配置** | OpenAI 兼容接口的 baseURL / apiKey / model / temperature / maxTokens / 签名 |
| **高级** | 仿人打字速度、评论间发送延迟（默认 3~8 秒） |
| **日志** | 实时滚动；最多保留 200 行 |

### 三种回复模式

| 模式 | 行为 | 适用 |
|------|------|------|
| **纯模板** | 从预设回复中随机选 | 第一次跑、测试效果 |
| **纯 LLM** | 每条调 AI 生成；调用失败该条跳过 | 模型可用且账户有充足 quota |
| **混合**（推荐） | 先 LLM；非 401/429 失败回退模板；401/429 直接停止整轮 | 日常 |

### 定时扫描

- 间隔 ≥ 5 分钟（小于会拒绝保存）
- 跑完一轮排下一次（不堆积），所以**实际间隔 = 配置间隔 + 上一轮耗时**
- 离开评论管理页 → 自动暂停定时器；回到此页 → 自动恢复
- 关闭浏览器后定时停止；重开页面后会**根据保存的 `schedule.enabled` 自动恢复**
- **前提：页面必须保持打开**。脚本依赖浏览器的 `setTimeout`，关掉标签即停

### 第一次跑（建议小号）

```
1. 模式选「纯模板」
2. 模板里写 2~3 条短回复
3. 作品数 N 设 1
4. 启用开关打开
5. 点「💾 保存」
6. 点「▶ 开始」
7. 看日志面板，每条评论应有 → 已回复 ✓
```

确认无误后再切到「混合」模式 + 配 LLM。

## 安全提醒

- **API Key 仅存在 GM_setValue（Tampermonkey 沙箱）**，不上传任何服务器，但仍是明文。给本脚本配额度受限的 key
- 默认延迟 3~8 秒/条 + 仿人打字 30~80ms/字。**别擅自调低，抖音风控会限流**
- 内置内容过滤：含微信/vx/v信/加我/私信我/联系方式/8 位以上数字 → 自动跳过该条
- 回复末尾自动追加 AI 签名（可在面板修改），便于事后辨识

## 故障排查

### 看不到 🤖 按钮

- Tampermonkey 图标有红叉 → 启用扩展
- 当前 URL 不在 `creator.douyin.com/creator-micro/comment-manage*` → 切回该页
- DevTools Console 没有 `[抖音自动回复] loaded` → `@match` 不匹配，检查脚本头是否被改

### 不回复任何评论

- 「启用」开关没打开 → 打开
- 选择「纯模板」但模板列表为空 → 加几条模板
- 日志显示"作品 #1 选择失败：waitFor timeout" → 抖音 DOM 改版，看下条

### DOM 选择器失效（最常见的故障）

抖音页面会更新。脚本所有选择器集中在文件顶部 `SELECTORS` 常量：

```javascript
const SELECTORS = {
  worksOpenBtnText: "选择作品",
  worksItemFallbackImg: 'img[src*="aweme"]',
  unrepliedTabText: "未回复",
  replyBtnText: "回复",
  sendBtnText: "发送",
  editorContentEditable: '[contenteditable="true"]',
  ...
};
```

定位方法：F12 → Elements → 找失效的元素 → 抓一个**稳定的属性**（class 或 data-*）→ 改 `SELECTORS` → Tampermonkey 编辑器里改对应行 → Ctrl+S → 刷新页面。

### LLM 调用失败

- `LLM 401` → apiKey 错；混合模式下会**直接停止整轮**避免烧 quota
- `LLM 429` → 限流，同上
- `LLM ECONNREFUSED` → baseURL 不通；常见错误：少了 `/v1` 后缀
- 超时（默认 15s）→ 检查模型是否合理（推理模型可能很慢）

### 回复"发送中..." 后没动静

- 输入框输进去了但发送按钮一直 disabled → 抖音前端校验未通过；通常是字数太长或包含敏感词。看面板日志
- 评论已发出但脚本没识别为成功 → 等待评论从未回复列表消失的逻辑出错；通常 8 秒后超时，会跳过下一条，不至于卡死

## 与 Node.js 工具的区别

| 维度 | 油猴脚本 | Node.js 工具 |
|------|---------|-------------|
| 部署 | 一键安装 | 装 Node + Playwright + 依赖 |
| 运行 | 浏览器内 | 后台 Playwright |
| 数据持久化 | GM_setValue | SQLite |
| 历史评论分析 | ❌ | ✅ |
| 评论图片下载 | ❌ | ✅ |
| 评论用户画像 | ❌ | ✅ |
| 定时调度 | 浏览器 setTimeout（页面常驻） | node-cron（后台守护） |
| 适合规模 | 每天 < 200 条 | 大批量、长期任务 |

两者**回复生成风格一致**（同一个 system prompt、同一套过滤规则）。
